# Development of Django Apps

When you are asked to generate code, or to plan for generating code, identify which of the below skills are needed and apply them.

## Skills

### Django model

A Django ORM model class (e.g. using `SingleLineTextField` for short strings).
→ [dj-write-model](./skills/dj-write-model.md)

### API view

REST API view structure, permissions, and data specs.
→ [dj-write-api-view](./skills/dj-write-api-view.md)

### Serializer

Django REST framework serializer patterns.
→ [dj-write-serializer](./skills/dj-write-serializer.md)

### URLs

URL configuration patterns.
→ [dj-write-urls](./skills/dj-write-urls.md)

### Permissions

Permission class patterns.
→ [dj-write-permissions](./skills/dj-write-permissions.md)

### Admin

Django admin configuration.
→ [dj-write-admin](./skills/dj-write-admin.md)

### Factories

Factory classes for testing.
→ [dj-write-factories](./skills/dj-write-factories.md)

### Schema

Pydantic classes that describe the internal structure of a JSON blob.
→ [dj-write-schema](./skills/dj-write-schema.md)

### Shortcuts

Shortcut function patterns.
→ [dj-write-shortcuts](./skills/dj-write-shortcuts.md)

### Tests

Tests for actions, API views, and permissions.
→ [dj-write-tests](./skills/dj-write-tests.md)

### Settings

Django/application settings patterns.
→ [dj-write-settings](./skills/dj-write-settings.md)

---

## Key Principles

- **Snake_case file names** — convert PascalCase spec names to snake_case
- **Follow the examples** — the blogs_be example serves as the primary reference template
- **Explicit is better** — when in doubt, ask for spec clarification rather than guessing
