# Project description

The software is developed in four phases (design, tests, code, scenarios), which are described in the
[development workflow](../development_workflow.md).

The specs live in the `extra/spec_src` directory: the design doc in `design/`, and the scenarios in `scenarios/`. In
a practical application, the spec_src files are compiled into markdown files in the doc/spec directory, but we leave
this step out of consideration.

## The use of an example application

The rest of the software development process is explained using the bookie example application.
