Before writing any code, you MUST:

1. Read ./instructions/index.md
2. Follow the spec-driven development process that is described in the instructions.

In this project, a "skill" means an instruction file at `instructions/<layer>_layer/skills/<name>.md`, not a
skill of the agent's own Skill tool. When asked to use a skill by name, locate it with
`find -L instructions -name '<name>.md'` and follow it. Only use the Skill tool for a name that is not found there.
